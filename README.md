# Deco Explore

Public articles, full-resolution images, previews and downloadable creations for Explore in Deco on iOS. This repository is separate from Deco Live for macOS and is the authoring home for these files.

`manifest.json` lists supported article locales and image paths. Article Markdown lives in `<locale>/<story-id>.md`, artwork in `Explore/<section>/<image-name>.png`, and downloadable content in `Media`. Preserve the stable names and links when editing.
