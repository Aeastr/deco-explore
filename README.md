# Deco Explore

Public articles, images, previews and downloadable creations for Explore in Deco on iOS. This repository is separate from Deco Live for macOS.

Our app uses a reviewed commit revision and caches downloaded files for offline access. Card metadata and supported in-app actions remain in the app. We retain original authoring content in the private Deco project under Design/Explore.

`manifest.json` lists supported article locales and image paths. Articles use `<locale>/<story-id>.md`, keeping stable story IDs, image references and action URLs. New content revisions are published here and selected by the app after validation. Files at a selected commit must remain available.
